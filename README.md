# Jiwon Kim

Statistics @ Ewha Womans University

## Projects

### [Smart Factory Power Forecasting](https://github.com/jiiwon129/Smart-Factory-Power-Forecasting)
Analyzed equipment-level power patterns and forecast electricity demand using **K-means clustering and an ensemble of cluster-level and process-wide forecasts**.

### [Travel Analytics for Solo Travelers](https://github.com/jiiwon129/Travel-Analytics-for-Solo-Travelers)
Combined travel survey and transportation data to **build an infrastructure index, predict solo-traveler spending, and explore improvement scenarios for tourism policy**.

### [Stock Direction Prediction](https://github.com/jiiwon129/Stock-Direction-Prediction)
Predicted **daily stock movements in five categories** using pre-market information and historical return distributions, with checks on input timing and consistency after code changes.

### [High-Frequency Volatility Modeling](https://github.com/jiiwon129/High-Frequency-Volatility-Modeling)
Implemented high-dimensional volatility matrix estimation, decomposition, and forecasting in Python using **one-minute data for 200 S&P 500 stocks** during a POSTECH FBDA Lab internship.

### [LG Aimers Pitch Control](https://github.com/jiiwon129/LG-Aimers-Pitch-Control)
Predicted pitch control success probabilities using pre-pitch game information and historical records. **Team rank: 94/1,087 (top 8.6%)**.

Project documentation is primarily in Korean.
